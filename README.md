# Stonegrid Concrete website demo

A responsive React + Bootstrap 5 corporate website concept for Stonegrid Concrete Pvt. Ltd.

## Run locally
1. Install Node.js (18 or newer).
2. Extract this folder.
3. In the project directory run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Before showing/publishing to the client
- Replace the illustrative Unsplash images with approved Stonegrid product/project photos.
- Confirm the official phone number, email, address and social links.
- Replace the demo contact form with a real form endpoint or CRM integration.
- Verify product names, specifications, manufacturing claims and service coverage with the business.
- Add actual project photos only with permission.

This is a frontend-only demo. The enquiry form validates in the browser and shows a demo confirmation; it does not send or store submissions.
